# 생태계 조사대 — 과학 2단원 3차시

## 학생 입장
7차시 ‘우리의 생태계’ 웹앱과 같은 방식입니다.
1. 웹앱 기본 주소에 접속합니다.
2. 학생 번호와 이름을 입력합니다.
3. 1~6모둠 버튼에서 자기 모둠을 선택합니다.
4. ‘참여하기’를 누릅니다.
수업 코드는 입력하지 않습니다. 교사가 가장 최근 연 수업으로 연결됩니다. 기존 수업은 교사 화면의 ‘이 수업으로 학생 입장 열기’로 현재 수업으로 다시 선택할 수 있습니다. 기존 공통 링크와 개별 모둠 링크도 호환됩니다.

## 생태계 지정
학생 입장 시 모둠별 생태계를 자동 배정하지 않습니다. 모둠원들이 의논하고 교사가 지정합니다.
- 학생: 생태계 지정 대기 화면에서 모둠원과 이야기합니다. 토의창 의견 공유도 가능합니다.
- 교사: 모둠별 입장 학생을 확인하고 바다·강·숲 중 하나를 선택해 ‘지정하기’를 누릅니다.
- 같은 생태계를 여러 모둠에 지정할 수 있습니다.
- 지정된 모둠의 모든 학생 화면은 약 2초 안에 탐구 화면으로 전환됩니다.
- 학생이 생태계 지정 전 구성요소를 조사·분류할 수 없도록 서버에서도 확인합니다.
- 조사 기록이 있는 모둠의 생태계를 변경할 때 확인창이 나오며, 이전 자료는 서버의 history 하위 컬렉션에 보관됩니다. 기존 제출 자료가 새 생태계 결과로 섞이지 않게 현재 결과를 비웁니다.
- 기존 수업의 이미 저장된 결과는 자동 삭제하지 않습니다. 완전히 새로 시작하려면 새 수업을 여세요.

## 조사와 제출
조사 바구니, 분류, 분류 근거, 토의 의견, 탐구 정리는 모둠원에게 약 2초마다 공유됩니다. 다른 요소를 동시에 수정한 작업은 서버에서 합쳐 저장합니다. 같은 문장이나 카드를 동시에 수정하면 나중에 처리된 입력이 적용됩니다.
‘첫 분류 완료’는 모둠 안에만 저장합니다. ‘최종 탐구 결과 제출’은 모둠원 한 명이 누르면 됩니다. 교사에게는 최종 제출한 자료만 보입니다. 토의 채팅은 모둠 안에서만 공유합니다.
교사 비교 화면은 바다·강·숲별 실제 제출 모둠을 모아서 보여줍니다. 고정된 모둠 짝은 없습니다.
잘못된 모둠으로 들어간 경우 ‘모둠 다시 선택’을 누르세요. 모둠 작품은 보존되며 같은 기기의 입장 명단은 새 모둠으로 이동합니다.

- teacher 링크의 접근 키는 교사만 보관합니다. 학생은 기본 주소만 사용합니다.
