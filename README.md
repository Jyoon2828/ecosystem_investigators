# 생태계 조사대 — GitHub · Vercel

초등 4학년 과학 2단원 3차시. 조사 → 분류 → 비교·재조사.

## 사용 흐름
- 선생님: 첫 화면에서 ‘교사 · 모둠 수업 만들기’를 누릅니다.
- 학생 공통 입장 링크 하나가 만들어집니다. 모든 학생이 공통 링크로 접속하고 자신의 모둠을 선택합니다. 바다 1·2모둠 / 강 3·4모둠 / 숲 5·6모둠으로 자동 배정됩니다.
- 공통 링크를 모든 학생에게 전달합니다. 학생이 모둠을 선택하면 같은 모둠 작업으로 연결됩니다. 조사 바구니, 분류, 근거, 탐구 정리와 토의 의견을 공유합니다. 모둠원 화면은 2초마다 갱신됩니다.
- 교사 화면은 모둠원이 최종 제출한 결과만 4초마다 받아옵니다. 첫 분류 완료는 모둠 내 기록만 저장하며, 모둠원 한 명이 최종 제출하면 됩니다. 제출 이후의 조사·분류 수정은 재제출 전까지 교사 결과에 반영되지 않습니다. 토의 채팅은 모둠 안에서만 공유합니다. 교사 링크를 보관하면 같은 수업을 다시 열 수 있습니다.
- 학생: 장면의 요소 선택 → 조사 바구니에 담기 → 드래그 또는 카드·분류 칸 누르기 → 첫 분류 완료 → 교사 화면으로 다른 모둠과 비교 → 조사 자료 재확인 → 분류 수정 → 탐구 정리 제출.
- 분류는 ‘살아 있는 것/살아 있지 않은 것’, 임시로 ‘더 알아볼 것’에 둘 수 있습니다.
- 학생에게 즉시 정답을 공개하지 않습니다. 교사가 마지막에 개념 정리를 켭니다.
- ‘혼자 먼저 탐험하기’는 Firebase 연결 없이도 가능하며 이 기기에 저장됩니다.
- JSON 다운로드는 탐구 기록 보관용입니다.

## 배포
1. 압축을 풀고 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. Firebase 프로젝트에서 Cloud Firestore 데이터베이스를 준비합니다.
3. Firebase Admin SDK 서비스 계정 자격 증명을 준비합니다. 공식 안내: https://firebase.google.com/docs/admin/setup
4. Vercel에서 저장소를 가져옵니다. Framework Preset은 Next.js입니다.
5. Vercel 환경변수 `FIREBASE_SERVICE_ACCOUNT_JSON`에 서비스 계정 JSON 전체를 설정합니다. 서비스 계정 파일은 GitHub에 올리지 말고 서버 환경변수에만 넣습니다.
6. 배포 후 모둠 수업을 만들어 연결을 확인합니다.
7. 클라이언트가 Firestore에 직접 접근하지 않습니다. 새 전용 프로젝트에서는 첨부 firestore.rules로 직접 접근을 막을 수 있습니다. 다른 앱이 사용하는 프로젝트의 규칙을 통째로 교체하지 마세요.

## 로컬 실행
Node.js 22 이상. `npm install` 후 `npm run dev`. 실시간 수업은 `.env.local`에 서버 환경변수를 설정해야 합니다.

## 범위와 자료
- 모둠원 각자 접속할 수 있습니다. 서로 다른 요소의 작업은 서버에서 합쳐 저장합니다. 같은 카드의 분류나 같은 근거 문장을 동시에 수정하면 서버가 나중에 처리한 입력을 적용합니다. 실패한 작업은 재시도하며 동일 작업의 중복 적용을 막습니다.
- 생성 이미지 3장과 확대 사진 아틀라스를 포함합니다. 실감 나는 수업용 이미지이며 실제 조사 장소에서 촬영된 사진은 아닙니다.
- 생물의 관계, 먹이사슬, 오염 실험은 이번 차시에 포함하지 않습니다.
- 흙 자체와 흙 속 생물, 돌 자체와 표면의 생물을 구분하는 설명을 포함합니다.
- 이미지 속 해조류는 특정 종의 정확한 사진 식별을 요구하지 않도록 ‘해조류’로 제시합니다.
- 교사 링크에 수업 접근 키가 포함됩니다. 학생에게는 학생 공통 입장 링크만 전달합니다.
- 학생 이름·회원가입 없이 사용합니다.

## 확인
Sites용 원본은 TypeScript 검사와 운영 빌드를 통과했습니다. 이 패키지는 같은 화면을 Next.js와 Firebase 서버 API로 옮긴 버전이며 Next.js 운영 빌드와 TypeScript 검사를 통과했습니다. 실제 Firebase 자격 증명 연결과 Vercel 운영 환경 검증은 배포 후 필요합니다.

## Firebase 연결 오류 확인
현재 ‘Firebase 서버 설정이 필요합니다’는 서버 환경변수가 없을 때만 나오는 문구입니다.
Vercel의 이 프로젝트 Settings → Environment Variables에서 정확한 이름 `FIREBASE_SERVICE_ACCOUNT_JSON`과 값(JSON 전체)을 확인하세요. Production에 적용되게 등록하고 새로 Redeploy해야 합니다. 값은 파일 경로나 firebaseConfig가 아닙니다. 서버용 서비스 계정 JSON 전체입니다. 비공개 키는 GitHub나 채팅에 공유하지 마세요.
수정된 코드는 변수 누락, JSON 형식 오류, 필수 필드 누락을 구분해 표시합니다. 실제 자격 증명 및 Firestore 권한은 선생님의 Vercel 배포에서 확인해야 합니다.
